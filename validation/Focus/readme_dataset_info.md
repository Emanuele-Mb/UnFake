This folder contains the scripts to run Focus validation using the GVFC dataset, which covers the following focuses:
  1) Economic
  2) Resources 
  3) Morality
  4) Fairness
  5) Legal
  6) Policy
  7) Crime
  8) Security
  9) Health
  10) Quality of Life 
  11) Cultural Identity 
  12) Public Opinion 
  13) Political
  14) Other
